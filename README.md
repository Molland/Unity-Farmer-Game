## Контрольные вопросы

### 1. Зачем в команде запуска CLI использовать флаг `-nographics` и какую роль он сыграет, когда мы перенесем пайплайн на удаленный сервер в облако?

Флаг `-nographics` отключает инициализацию графического движка и видеокарты Unity. Он необходим для работы сборки на серверах, где отсутствует графическая оболочка.

При переносе пайплайна на удалённый сервер в облако данный флаг позволит выполнять сборку в режиме **Headless**, без необходимости в подключённом мониторе или графическом интерфейсе.

### 2. Что произойдет, если запустить консольную сборку проекта, в настройках Build Settings которого не выбрана ни одна сцена игры? Какая строка нашего кода обрабатывает эту ситуацию?

Если в `Build Settings` не выбрана ни одна активная сцена, сборка будет остановлена, а в лог будет выведено сообщение об ошибке.

Данную ситуацию обрабатывает условие:

```csharp
if (levels.Length == 0)
```

После него вызывается:

```csharp
ExitWithCode(1);
return;
```

Таким образом, при отсутствии активных сцен сборка не запускается.

### 3. Почему класс `BuildManager` и его методы обязательно должны быть объявлены как `public static`?

Класс и методы должны быть `public static`, потому что Unity вызывает метод сборки напрямую из командной строки через параметр:

```csharp
-executeMethod BuildManager.BuildWebGL
```

Unity должна иметь возможность найти класс `uildManager` и вызвать метод `BuildWebGL()` без создания экземпляра класса. Поэтому метод объявляется как `public static`.
